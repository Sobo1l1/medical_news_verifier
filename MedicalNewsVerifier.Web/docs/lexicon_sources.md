# Источники лексиконов (эмоциональная / субъективная лексика)

## Файлы в `Resources/Lexicons`

| Файл | Назначение |
|------|------------|
| `emotional_ru.txt`, `emotional_en.txt` | Базовые учебные списки в репозитории. |
| `emotional_ru_rusentilex.txt` | **Автогенерация**: `python/tools/build_lexicons.py --use-seed` или импорт из внешнего дампа (`--input`). |

## RuSentiLex и табличные корпуса

- **RuSentiLex** (Linguateca / исследовательские публикации): лексикон сентимента для русского; форматы различаются по версии. Скрипт `build_lexicons.py` ожидает **построчный** или **TSV/CSV**, где первая колонка — слово/лемма. Полярность и POS при необходимости фильтруйте вручную до импорта.
- Полный импорт: скачайте файл, затем:
  `python python/tools/build_lexicons.py --input путь/к/файлу.tsv --max-words 12000`
  При необходимости объедините с seed: добавьте в скрипт второй вызов или запустите дважды с разными `--output` и объедините вручную (или расширьте скрипт флагом `--merge-seed`).

## NRC Emotion / WordNet-Affect

- В основном ориентированы на **английский** язык. Для русского MVP предпочтительнее RuSentiLex и русские субъективные списки. Английские корпуса можно подмешивать в `emotional_en.txt` отдельным конвейером.

## Лицензии

- Перед включением стороннего корпуса в репозиторий проверьте **лицензию** первоисточника и условия атрибуции.
- Строки в `python/tools/seeds/subjective_ru_seed.txt` — учебная подборка для демонстрации пайплайна; не является выгрузкой RuSentiLex.
